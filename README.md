### 🧠 [Nyxara AI](https://github.com/nyxaraindia/Nyxara-Ai)

**Focus:** Language models · Model architecture · Tokenization · Training and evaluation

### 📒 [ESVRO](https://github.com/nyxaraindia/ESVRO)
A Flutter and SQLite bookkeeping ecosystem for shop owners and accountants. ESVRO is designed around a deterministic financial core, with AI kept separate to support traceable, human-approved records.

**Built with:** Flutter · SQLite · AI-assisted workflows
